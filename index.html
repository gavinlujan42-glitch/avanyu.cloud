01 / RELEASE

Confirm the payload

  • Record intended page and commit SHA
  • Verify CNAME and Pages source
  • Assign launch and rollback ownership
02 / CUTOVER

Secure the route

  • Validate apex and www DNS records
  • Remove conflicting records or forwarding
  • Enforce HTTPS after certificate issuance
03 / AVAILABILITY

Prove the system

  • Require HTTPS 200 and clean redirects
  • Test Leaflet, map tiles, USGS, CSS, and JS
  • Run desktop, mobile, CTA, and console checks
04 / OPERATE

Watch and recover

  • Monitor feeds, maps, uptime, and certificates
  • Document degraded-mode behavior
  • Retain and test the rollback commit
LAUNCH AUTHORITYGO only when DNS, HTTPS, core assets, live services, and rollback all pass.
